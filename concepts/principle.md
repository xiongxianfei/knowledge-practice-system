# Principle

## Key takeaway

A Principle explains a reusable relationship; a rule chooses an implementation.

## Summary

A KPS Principle is a scoped explanatory relationship that remains meaningful beyond one particular design. It may be scientific, empirical or reasoned domain knowledge. It need not be an irreducible first principle, and it does not have to dictate one unique Method.

## Definition and use

A reusable, scoped explanatory relationship that makes more than one possible Model or Method intelligible.

“Independently editable equivalents can diverge” describes a possibility and explains a maintenance problem. “Every file must link to one source of truth” chooses a response. Synchronization, generated views and explicit reconciliation are other possible responses to the same relationship.

## Boundary and non example

Declarative grammar is a useful cue, not sufficient proof of classification. A mandatory cardinality rewritten as “there is exactly one parent” is still a model convention, not an established explanatory Principle.
