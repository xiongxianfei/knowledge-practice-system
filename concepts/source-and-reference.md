# Source and Reference

## Key takeaway

The source is external material; the Reference is the local record of its identity and contribution.

## Summary

A source is a publication, dataset or other original material. A Reference is a Markdown record identifying it, locating the relevant support, stating access limits and separating that support from KPS inference. This package stores records, not copies of external publications.

## Definition and use

A Source is the external material. A Reference is the local record identifying it, the inspected scope and the claim-specific contribution.

Use creator–year–short-title filenames when the year is established. An undated webpage stays undated; its access date is a separate field. Several URLs for one paper do not constitute independent studies.

## Boundary and non example

A reference summary permits local understanding, not independent verification of unseen source text. Disclose abstract-only access, unavailable sections and known corrections.

## Local evidence and uncertainty

This file uses KPS’s declared conventions or an explicit reasoning argument rather than claiming an externally tested intervention. Its explanation and counterexample are local; linked objects identify reusable connections, not independent confirmation.
