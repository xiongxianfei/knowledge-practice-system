# Observation and interpretation

## Key takeaway

Preserve what was observed separately from the explanation attached to it.

## Summary

An observation records a measurement, visible event or report of experience. An interpretation proposes what it means or what caused it. Both can be mistaken, but they require different checks: observation checks concern how information was obtained; interpretation checks concern alternative explanations.

## Definition and use

An observation records what was measured, seen or reported; an interpretation proposes its significance or explanation.

“The link returned not found” is an observed event. “The identifier design failed” is one explanation; the file might instead be missing or the path mistyped. Correcting a recording error should leave an explicit correction rather than silently changing the past.

## Boundary and non example

This is a working distinction, not a claim that perception is theory-free. Note the observer, instrument, context and uncertainty when relevant.
