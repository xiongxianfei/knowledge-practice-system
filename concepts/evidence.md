# Evidence

## Key takeaway

Evidence is support for a particular claim, not a property conferred by a citation.

## Summary

Evidence is information that bears on an assertion within a specified context. A measurement, observation, source passage or formal argument has to be connected to the exact assertion it supports. A source can be credible yet answer a different question.

## Definition and use

Information bearing on a particular claim under particular conditions.

A before/after task completion time may support “this run was faster.” It does not by itself support “the new structure caused the improvement”: effort, task difficulty and order may differ. A formal derivation supports its conclusion only under its premises.

## Boundary and non example

Distinguish evidence, inference and a chosen convention. The existence of this five-folder system is a design fact, not an effectiveness experiment.
