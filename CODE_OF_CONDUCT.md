# Code of conduct

## Key takeaway
Respectful, evidence-focused disagreement and constructive review are expected in KPS discussions and contributions.

## Summary
Respectful, evidence-focused disagreement and constructive review are expected in KPS discussions and contributions.

## Expected conduct
Treat participants respectfully; critique claims and methods rather than people. Welcome constructive correction and differing expertise. Provide reproducible examples where practical. Recognize that an apparently authoritative statement can still have limited scope.

## Unacceptable conduct
Harassment, threats, discriminatory abuse, doxxing, publication of private conversations or sensitive personal data, and repeated hostile disruption of discussion are not acceptable. Technical or scholarly disagreements are not themselves misconduct.

## Scope and enforcement
This code applies to repository issues, pull requests, discussions and other spaces officially associated with KPS. Maintainers may remove comments, close threads or limit participation to protect contributors. Decisions should be proportionate and documented when appropriate.

## Reporting
Do not post sensitive reports or personal information publicly. Before the first public launch, the repository owner should configure and announce a **private reporting contact** in GitHub repository settings or this document. Until one exists, GitHub's own report-abuse controls are available for platform policy violations; do not assume public issues are confidential.

## Version
This is a short project-authored code of conduct, not a claim to be an official Contributor Covenant template. Maintainers may adopt a standard template with a real enforcement contact in a later release.
