# Spaced retrieval absolute spacing enhances learning regardless of relative spacing

## Key takeaway

This experiment examines spacing of repeated retrieval and delayed retention.

## Summary

This experiment examines spacing of repeated retrieval and delayed retention. It can inform a review question about when recall is repeated. It does not specify an optimal universal schedule or establish the value of the KPS folder architecture.

## Absolute and relative retrieval spacing
